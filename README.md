# Master Portfolio Site

A professional, high-performance personal portfolio website designed to showcase projects, skills, and services. The site features a premium "Obsidian & Gold" aesthetic with a fully functional Dark/Light mode toggle, responsive design, and modern UI elements like glassmorphism and gradient text.

> **Overview**: A deep dive into my work with Java, Python, and SQL. Featuring interactive project showcases and a collection of my solved DSA challenges.

## 🚀 Features

* **Premium Design**:
    * **Dark Mode (Default)**: Deep Obsidian background with Metallic Gold accents.
    * **Light Mode**: Porcelain background with Midnight Blue text and Midnight/Gold accents.
    * **Glassmorphism**: Modern, translucent card effects for projects and resumes.
    * **Gradient Text**: Gold-to-Silver gradient text effects for headings.
* **Theme System**:
    * Global Light/Dark theme toggle button in the navigation bar.
    * Theme preference is saved to `localStorage` (remembers your choice).
* **Fully Responsive**:
    * Optimized for Mobile, Tablet, and Desktop.
    * **Smart Image Scaling**: "Top-Center" alignment ensures subjects are never cut off.
* **Project Showcase**:
    * Dedicated detail pages for each project (**CarePlus**, **Solution/24**, **Big Tech Analytics**, etc.).
* **User Experience**:
    * Custom scrollbars and interactive hover effects.
    * "Backspace" keyboard shortcut for navigation restored.

## 🛠️ Technology Stack

* **Core**: HTML5, CSS3, JavaScript (ES6+).
* **Styling**: Bootstrap 4, Custom CSS Variables (for theming).
* **Libraries**:
    * jQuery, Owl Carousel, Magnific Popup, AOS (Animate On Scroll).

## 📂 Project Structure

* `index.html`: Main landing page (Home, About, Resume, Skills, Contact).
* `css/style.css`: Main stylesheet containing all premium styles and variables.
* `js/theme-toggle.js`: Logic for handling the Light/Dark mode switch.
* `project-*.html`: Individual case study pages for portfolio items.

## 🔧 How to Run

1. Simply open `index.html` in any modern web browser.
2. No build step required, though a local server is recommended for smoother loading.
